# upswell
Upswell: trend insights for Etsy sellers. Upswell uses public listing and shop statistics from the Etsy Open API to show sellers which product themes are emerging in their niches. It does not scrape Etsy or access private shop data. The term 'Etsy' is a trademark of Etsy, Inc. This application uses the Etsy API but is not endorsed or certified by Etsy, Inc.
