Privacy Policy

Upswell is an independent research project that helps Etsy sellers spot product themes that are gaining interest. This policy explains what data Upswell uses and what it doesn't. Upswell is currently a research preview with no public sign-ups.

What Upswell collects about you

Nothing, today. This website has no sign-up forms, analytics trackers or advertising cookies, and doesn't record who you are. It's hosted on GitHub Pages; GitHub may log technical request data as described in GitHub's privacy statement.

The research dashboard is private and used only by its developer for testing. If Upswell opens to users, this policy will be updated before any account data is collected, to say exactly what is stored (for example, the email address used to sign in) and why.

Data Upswell reads from other services

Upswell reads only public, aggregate-level data through official APIs, within each service's terms:

  • Etsy Open API: public listing and shop statistics, such as favorite counts, view counts, listing tags and a shop's public sales count. No private shop data, buyer information, messages or receipts.
  • Pinterest API (Trends): trending search keywords and their growth rates. No Pinterest user data, boards, Pins or account information.

Upswell never scrapes websites, never posts or writes to these services, and never sells or shares the data it reads.

How long data is kept

  • Raw listing statistics are kept briefly (no more than 30 days, or less if a service's caching rules require it), then deleted automatically.
  • Derived trend history is kept long term. These are Upswell's own calculations, such as "theme X gained N favorites on day D", and contain no personal information.

Children

Upswell isn't directed at children and doesn't knowingly collect data from anyone.

Changes

Changes to this policy are published on this page with a new "last updated" date. The full history is public in the project's GitHub repository.
